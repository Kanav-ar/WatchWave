# WatchWave
A full stack video platform where users can upload and share video creations and can interact with other user's content through likes, shares and comments.

---

## Features
- User authentication and authorization
- Video upload functionality
- Like, comment and share system
- Responsive UI
- JWT authorization
- REST API integration
- Interactive user posts

---

## Tech Stack 
- ### Frontend: React.js, Tailwind CSS, Redux Toolkit
- ### Backend:  Node.js, Express.js
- ### DataBase: MongoDB
